
<h2 class="wp-block-heading">前書き</h2>



<div class="wp-block-group">
<p>このリポジトリは、sedコマンドを実行して与えられた文字列から指定した文字で1回だけ置換する場合と複数置換する場合を体験できます</p>
</div>



<h2 class="wp-block-heading">インストールする必要のあるコマンド</h2>



<div class="wp-block-group">
<ol class="wp-block-list">
<li>特に無し</li>
</ol>
</div>

<h2 class="wp-block-heading">後書き</h2>



<div class="wp-block-group">
<p>'s/e/E/'は行で一番初めに合致したeをEに置換するだけですが、's/e/E/g'はgのglobalオプションをつけることで行に出現するeを全てEに置換します<br>以下のコードを実行して各行の文字列が置換されていることを確認してみてください</p>



<pre class="wp-block-own-copy-code-line-block wp-block-code has-24292-eff-color has-cyan-bluish-gray-background-color has-text-color has-background has-1-125-rem-font-size"><code>echo -e "apple\nbanana\ncherry" | sed 's/a/A/'
echo -e "apple\nbanana\ncherry" | sed 's/a/A/g'</code></pre>
